What each value means

  • static: default flow; top/left do not move it.
  • relative: offsets from its normal spot; original space remains.
  • absolute: removed from normal flow; positioned against the nearest ancestor whose position is not static.
  • fixed: positioned against the viewport; usually stays put while the page scrolls.
  • sticky: behaves normally until it reaches a scroll threshold, then sticks within its scrolling container.
