# Intro — Git Series

A series intro, not a technical lecture - this names what Git actually
is, the teaching philosophy, and the two tools needed to follow along.

---

## What Git actually is

**Version control** = checkpoints for software, the same idea as a save
point in a game. When something breaks, you go back to a point where it
worked and start again from there.

---

## The one distinction to get right immediately

| | What it is |
|---|---|
| **Git** | the actual software - what this whole series teaches |
| **GitHub** | one *service provider* that hosts Git repos - not the same thing as Git itself |

Others exist too (Bitbucket, and more) - GitHub is just the most common one.

---

## The teaching philosophy

Not memorizing commands - understanding the **workflow**: what a git
repo actually contains behind the scenes (the `.git` folder), and what
happens when things go right or wrong.

---

## Tools needed

| Tool | Why |
|---|---|
| A terminal | Git is fundamentally a terminal-first tool - GUIs exist, but the command line is how it's actually learned here (instructor uses Warp; any terminal works) |
| VS Code | just as a text editor - no actual programming language is used, since this series is language-independent |
